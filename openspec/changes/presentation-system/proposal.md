# Proposal：簡報系統

## 背景與問題

現有活動（如知識型高峰會）需要一套線上簡報展示系統，供各場地在指定時段播放簡報內容。目前缺乏：

- 統一的多場地管理機制
- 時段鎖定（避免提前洩漏內容）
- 防截圖／防下載保護
- 集中式後台管理

## 目標

建立一套以 Next.js 開發的簡報管理與展示系統，風格對標 2026summit.sat.cool（深色科技感）。

## 核心需求

1. **多場地切換**：可同時管理多個場地，每個場地有獨立議程
2. **時段鎖定**：每份簡報有開始與結束時間，未到時間不得進入
3. **防截圖防下載**：透過 Canvas 渲染圖片、浮水印、失焦遮罩等手段保護內容
4. **後台管理**：管理員可設定場地、場次、上傳簡報圖片、管理帳號
5. **簡報格式**：每份簡報由多張圖片（PNG/JPG）組成，逐頁翻閱

## 不在範圍內（Out of Scope）

- 觀眾票券驗證（QR Code 掃票）
- 即時廣播控制（強制觀眾同步到某頁）
- PPTX / PDF 直接上傳轉換
- 多語言 i18n

## 成功指標

- 管理員可在 5 分鐘內完成場地＋場次＋簡報上傳設定
- 觀眾在時段外無法看到簡報內容
- 簡報圖片無法透過右鍵、快捷鍵直接儲存
